The manager app¶

CleanYourTV in LG's app list sets up, updates and removes everything. The left side of the screen explains the focused row.

Row Function
Launcher, Service Installed version; offers an update when the latest release is newer.
Check for updates Asks GitHub for the latest release.
Update channel Follow the stable releases or a test build.
Go back to launcher Appears after a launcher update.
CleanYourTV as Home Choose LG's Home or ours. The TV restarts.
Theme Choose a theme (with its screenshot and description) from the list on GitHub; Theme options has the accent colour and going back. See Themes.
Live TV Show Live TV (off hides it in the launcher and Inputs list and leaves the Guide button to LG), the Playlist (set up from your phone with a QR code and a 6-digit code), Refresh playlist and guide, Learn the Guide key, Clear recent channels and Remove the playlist. See Live TV.
Input key The takeover switch, Learn the Input key, Input key shows (the Inputs list over the running app, ready in the background or started when pressed, or the launcher's own list) and the optional Learn the Home key. See The Input key.
Voice Optional. Installs the speech recogniser (about 80 MB), learns the voice button, tries it, sets where the text goes. See Voice.
Network notifications Switch, address, token and an example for sending picture notifications from other devices.
Debloat Turns the debloat on or off.
Share log A QR code that opens a masked diagnostic report on a phone, with a Copy button.
Uninstall Removes everything and restarts the TV.

When the service is not running¶

The manager works without the service for two things: checking for a newer package and installing it, so a broken service can be repaired from the TV.

Share log¶

Share log opens a short-lived page on your local network (port 8768 or higher, a random address, ten minutes). Scan the QR code with a phone on the same network. It works even when the service is not running, so it can also report a failed setup.

The report is masked: addresses, MAC addresses and URL paths are replaced, and the values of token, key, password, pass, secret and apikey are removed. It holds the TV model and firmware, the versions, LG's stock Home app, the mounts and boot scripts, whether our apps are registered, your options, the remote key codes seen by the input hook, the service status, the setup log, the last lines of the service log and the input hook log. Attach it to bug reports.
