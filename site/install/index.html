Installing¶

Quick start¶

  1. Root the TV and install the Homebrew Channel (rootmy.tv).
  2. From your computer, run the install command with the TV's IP address (below). It installs the CleanYourTV manager app.
  3. On the TV, open CleanYourTV and choose Set up now. It takes about a minute and the screen blinks once.

That is all. The launcher is LG's Home from then on.

Requirements¶

  • An LG webOS TV rooted with the Homebrew Channel.
  • SSH access to the TV as root, which the Homebrew Channel can enable (Settings > SSH Server).
  • Internet access on the TV (the install command downloads the package from GitHub).
  • webOS 5 or newer (2020 models and later). webOS 4 and older are not supported: they have no systemd and an old Node.js, and the setup stops before it changes anything.
  • Firmware from the tested TVs, or one where LG's Home app is of the flutter or web kind; see What happens on unlisted firmware.

Give the TV a fixed address

Reserve a fixed IP address for the TV in your router so the install command and the network notification address never change.

Install steps¶

1. Install the manager app¶

From your computer, with your TV's IP address:

ssh root@192.168.1.50 'curl -fsSL https://raw.githubusercontent.com/lasharor/cleanyourtv-WebOS/main/install.sh | sh'

The script downloads the latest release package, checks its SHA-256 and installs it. Nothing else on the TV changes in this step. The package can also be downloaded from Releases and installed with the Homebrew Channel or ares-install.

2. Set up, on the TV¶

Open CleanYourTV from the app list, choose the options and Set up now.

Option Default
Debloat LG's ads and telemetry on
Take over the Input key on

The setup:

  1. saves the original state in /media/developer/cleanyourtv/backup;
  2. installs the launcher and the service;
  3. adds boot scripts to /var/lib/webosbrew/init.d/;
  4. replaces LG's Home at boot (in RAM) and starts the service;
  5. checks that the new Home came up. If it did not, it removes the boot scripts and restarts the TV with LG's Home.

Its log is /media/developer/cytv-setup.log, kept across the restart, with the service log next to it in cytv-setup.log.service.

The same setup over SSH 

sh /media/developer/apps/usr/palm/services/com.cleanyourtv.manager.service/bootstrap.sh install
Options: --no-debloat, --no-input-key, --no-start, --no-verify, --force.

Unlisted firmware¶

The setup matches the TV's firmware against compat.json (it fetches the newest copy from the repository and falls back to the one in the package). A listed firmware is set up directly. For an unlisted firmware the setup continues when LG's Home app is the flutter or web kind, and otherwise stops and offers Set up anyway. To add a firmware to the list, open an issue with the output of Share log (Troubleshooting).

Installing a test build¶

To try a change that is not released yet, install from a branch: see Updating and uninstalling.

Troubleshooting¶

  • The Home button opens LG's full-screen Home, not CleanYourTV. Some TVs have a Home Style setting. Set TV Settings > General > Home Settings > Home Style to Basic.
  • FAILED_IPKG_INSTALL. Remove the com.cleanyourtv.manager entry marked half-installed from /media/developer/apps/var/lib/opkg/status and install again.
  • Black screen after switching or rebooting. Wait a minute; if it stays black, restart the TV.
