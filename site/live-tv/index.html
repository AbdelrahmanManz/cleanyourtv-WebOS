Live TV¶

Plays an IPTV playlist (M3U) from your own provider or server. It does not use LG's tuner, and the project provides no channels and no playlist.

Setting it up¶

On first use the screen shows an address and a 6-digit code.

  1. Open the address on a phone or computer on the same network as the TV.
  2. Enter the code.
  3. Paste your M3U playlist address (and the XMLTV guide address if the playlist does not carry one).

The page closes by itself. It is open for ten minutes at most and only with the code.

From a shell on the TV instead:

curl -X POST localhost:8765/api/live/settings -d '{"playlistUrl":"http://...","epgUrl":"http://..."}'

Turning it off¶

Live TV is optional. In the manager app, Live TV > Show Live TV switches it on and off. Off hides it everywhere: the Live TV button and tile in the launcher, Live TV in the Inputs list, and the Guide key takeover (below). LG's own player and guide are used as before. The playlist and your favourites are kept, so switching it on again brings them back.

Back Return to the launcher Clear filters and search, then close the guide

The tabs are All channels, Favourites, Recent and one per category of your playlist. Channels show badges for country, language and quality when the playlist names them (for example NL, EN, HD). Filters narrow the list by country, language and quality; search matches names across all channels.

The Guide button¶

By default the remote's Guide button belongs to LG. In the manager app, Live TV > Learn the Guide key records the button's code; afterwards it opens the Live TV channel guide over whatever is running, and closes it again when Live TV is open. Clear gives LG's guide back. The button is only taken over while Live TV is on and a code is learned. It uses the same hook as the Input key.

How it plays¶

  • The TV's own player plays HLS (.m3u8).
  • Stepping through channels with Up/Down starts the new channel only when the keys have paused for 180 ms. Channels you skip are never requested from your provider, which matters for accounts that allow one connection.
  • The player uses one video element for the whole session instead of creating one per channel.
  • The guide (XMLTV) is refreshed twice a day and keeps 36 hours.
  • When a playlist lists the same channel in several qualities (for example HD and SD), they are merged into one channel with several streams. If one does not start, the next is tried; a stream that stalls is reloaded once.
  • When a channel does not play, the screen says why: the server refused it, the stream is gone, it needs DRM, it is not video, or it is too slow.
  • Statistics (Blue) show the resolution, buffer, dropped frames and which stream is playing.

There is no recording and no pause.

Where it is stored¶

The playlist address, which usually contains an access key, is stored only on the TV, in /media/developer/cleanyourtv/live/, readable by root only. To clear it:

curl -X POST localhost:8765/api/live/reset

Favourites, recent channels and the failed-channel list are stored in state.json in the same folder.
